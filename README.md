# Digitech 6 · Behind the Order

A Windows 11–style public-health law and ethics simulation for MIVA, built from the *Behind the Order* storyboard.

| Folder / file | What it is |
|---|---|
| [`app/`](app/README.md) | **The playable simulation** (React + TypeScript + Vite). Run `cd app && npm install && npm run dev`, then open http://localhost:5174 |
| [`walkthrough/`](walkthrough/transcript.md) | The finished 47-second narrated walkthrough (MP4, WebM, burned-caption MP4, SRT/VTT captions, transcript) |
| [`behind-the-order-walkthrough/`](behind-the-order-walkthrough/README.md) | HyperFrames source for the walkthrough film |
| [`reference/`](reference/) | DHIS2 and Windows 11 reference notes, plus DHIS2 documentation screenshots used for fidelity checks |
| `Behind_the_Order_Page_Designs_and_Build_Prompt.md` | The build prompt |
| `DT01_RD_03_03_Dataset Analysis Sandbox.pdf` | Source storyboard (Behind the Order is pp. 18–42) |
| `Fix_the_Prompt_Opener.zip` | MIVA logo opener package (adapted for this module) |

Before using this as a real assessment, read [`app/docs/CONTENT_FIXTURES.md`](app/docs/CONTENT_FIXTURES.md). The storyboard leaves gaps, and those gaps are filled with clearly labelled stand-in content that the content team needs to replace.
